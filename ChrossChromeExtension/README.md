# Extension Chross pour Google Chrome (et navigateurs Chromium)

Cette extension permet de contrôler Chross et de synchroniser vos onglets directement depuis votre navigateur (Chrome, Brave, Arc, Edge, Opera, Vivaldi).

## 🚀 Installation rapide dans Chrome

1. Ouvrez votre navigateur et accédez à l'adresse : **`chrome://extensions`**
2. Activez le **Mode développeur** (interrupteur en haut à droite).
3. Cliquez sur **Charger l'extension non empaquetée** (*Load unpacked*).
4. Sélectionnez le dossier **`ChrossChromeExtension`** situé dans votre dossier `chross`.
5. Épinglez l'icône Chross dans votre barre d'outils Chrome !

---

## ⚡️ Fonctionnalités incluses

- **Badge dynamique dans la barre d'outils** :
  - Affiche le temps écoulé en direct sur l'icône de l'extension (ex : `12m`, `1h15`).
  - Vert fluo Chross (`#D6FF3F`) lorsque la session est active.
  - Orange (`#FF9500`) avec indicateur `II` quand la session est en pause.
- **Contrôle complet du chrono** :
  - Démarrer une session (projet libre ou depuis vos Presets Chross).
  - Mettre en pause ou reprendre la session en 1 clic.
  - Arrêter et enregistrer la session.
- **Inspection et ajout automatique de sites** :
  - Détecte instantanément le nom de domaine de l'onglet actif.
  - Indique si le site fait déjà partie du périmètre de la session (`✓ Suivi dans la session`).
  - Ajout ou retrait d'un clic (+ ou ✕ dans la liste).
- **Raccourcis clavier globaux dans le navigateur** :
  - `⌥ + ⇧ + P` (ou `Command + Shift + P`) : Mettre en pause / Reprendre le chrono.
  - `⌥ + ⇧ + A` (ou `Command + Shift + A`) : Ajouter le site de l'onglet actuel à la session.
- **Menu contextuel (clic droit)** :
  - Clic droit sur n'importe quelle page ou lien : *« Ajouter ce site à la session Chross »*.
- **Barre de progression quotidienne** :
  - Visualisez en un coup d'œil votre temps de travail accompli aujourd'hui par rapport à votre objectif quotidien.
